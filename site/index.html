No tool calls

That text is the answer. The loop stops.

Tool calls

gateTool → Promise.all → append results → ask again. Bounded. At the bound it asks for a final answer.

steer reaches the model next round as <user_steer>. Stop aborts the turn AbortSignal. Skill catalog is a name + summary; the body loads only when the model calls skill.

Guild borrowed one Hermes shape for the browser snapshot — never the live Chrome profile. The turn loop is Guild’s own. Not a Codex app-server harness. Not an OS jail. Default sandbox is workspace_write. Opt in to full_access.

Files: packages/daemon/src/harness.ts · generate.ts · tools.ts · browser.ts.

05 · FAQ

Before you npx

Do I need an API key tonight?

No. OpenCode Free is the default path. Those prompts go to opencode.ai. Command Code is an optional subscription picker. Switch provider in /settings.

Does this tab talk to the hall?

No. Interactive preview — no model calls. Fixed replies. This tab does not talk to 127.0.0.1:7420.

Do I need to clone the repo?

No. Node ≥ 22.19 and npx @kevin5251984/guild web is enough. pnpm is only if you are reading the code.

What can run and write do?

Your shell, gated to the workspace. Unset GUILD_SANDBOX = workspace_write. Read SECURITY.md before you point this at a machine you care about.

Can I schedule a later hall turn?

Yes. Ask a seat, or open the sidebar sheet. Times read like speech — every 2h, in 30m, 0 9 * * * — and each job gets a sheet with pause, resume, and a test run that returns to that hall. A run cannot schedule another job.

What changed recently?

One guild master can open channels, create seats, and assign work, and stays off every roster. The hall eases open instead of snapping. Settings stays one roster, and Free stays a single row.
